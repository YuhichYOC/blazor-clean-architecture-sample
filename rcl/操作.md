# RCL 版で追加
```bash
$ dotnet new razorclasslib --name Sample.Presentation --output Sample.Presentation
$ dotnet add Sample.Presentation/Sample.Presentation.csproj reference Sample.Application/Sample.Application.csproj
$ dotnet add Sample.Web/Sample.Web.csproj reference Sample.Presentation/Sample.Presentation.csproj
$ dotnet sln Sample.sln add Sample.Presentation/Sample.Presentation.csproj
```
