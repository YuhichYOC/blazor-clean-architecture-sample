    - 【開発環境のみ】 ユーザーを docker グループへ追加 参照

# 開発用コンテナでのネットワーク設定
- 開発用コンテナでは devcontainer.json へ runArgs を追加
```json
{
  "name": "Debian 13 + .NET SDK",
  "build": {
    "dockerfile": "Dockerfile"
  },
  "workspaceFolder": "/workspaces/src",
  "forwardPorts": [],
  "customizations": {
    "vscode": {
      "extensions": [
        "ms-dotnettools.csharp"
      ]
    }
  },
  "mounts": [
    "source=${localWorkspaceFolder},target=/workspaces/src,type=bind,consistency=cached"
  ],
  "postCreateCommand": "dotnet --info",
  "runArgs": ["--network=bom-net"]
}
```

# 開発環境コンテナの準備
- プロジェクトディレクトリに .devcontainer ディレクトリを作成
- Dockerfile をプロジェクトディレクトリ/.devcontainer に配置
- devcontainer.json をプロジェクトディレクトリ/.devcontainer に配置
    - mounts の target と workspaceFolder は一致している必要がある, これはコンテナ内での作業ディレクトリ
- devcontainer.json を開く
    - Reopen in container
