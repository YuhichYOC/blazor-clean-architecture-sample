# Debian 13 ( Docker )
- docker をセットアップする
- sudo docker pull container-registry.oracle.com/database/free:latest

## メモ

### コンテナ内のコンソールを開くとき
- sudo docker exec -it oracle /bin/bash

### パスワードで避けた方がいい記号
- Linux シェルの都合で避けた方がいい
    - $ : 変数展開
    - ` : コマンド置換
    - \ : エスケープ
    - "
    - '
    - # : コメント
    - &, ;, | : 制御
    - *, ?, [, ] : グロブ
    - (, ), {, }, <, >, ~
    - ! : ヒストリ展開
- ORACLE のログインパスワードとして避けた方がいい
    - @
    - /

### パスワードに使用できる記号
- ALTER USER <ユーザー名> IDENTIFIED BY <パスワード> 構文で、クォートなしで入力できる文字
    - _
    - $
    - #


# 起動前・ネットワーク設定
- 開発用コンテナから ORACLE コンテナへ名前で接続先解決ができるようにする
    - コンテナは起動のたびに IPv4 アドレスが変わることがある
```bash
$ docker network create <ネットワーク名>
```

# 開発用ユーザー・スキーマの作成

## イメージで用意されている開発用 PDB ( FREEPDB1 ) へ接続
- ALTER SESSION SET CONTAINER = FREEPDB1;

### プラガブルデータベース一覧の確認
- SELECT * FROM V$PDBS;

## ユーザーの作成
- CREATE USER DEV_USER IDENTIFIED BY "9l6s7sIKR#3oED2B";

## 表領域の割り当て制限を無制限に設定
- ALTER USER DEV_USER DEFAULT TABLESPACE users QUOTA UNLIMITED ON users;

### 表領域の一覧
- PDB へ接続してから実行する
```sql
SELECT 
    t.tablespace_name 
  , t.status 
  , f.file_name
  , ROUND(f.bytes / 1024 / 1024, 2) AS size_mb 
FROM 
    dba_tablespaces t 
JOIN 
    dba_data_files f 
ON 
    t.tablespace_name = f.tablespace_name
;
```

## 基本的な権限を付与
- GRANT CONNECT, RESOURCE TO DEV_USER;

## 23ai / 23c 以降、RESOURCE ロールから外れた「表作成権限」などを明示的に付与
- GRANT CREATE TABLE, CREATE VIEW, CREATE SEQUENCE, CREATE PROCEDURE TO DEV_USER;


# コンテナ作成後からネットワーク設定を適用する場合
- コンテナの再作成で設定が消える点に注意
```bash
$ docker network create <ネットワーク名>
$ docker network connect <ネットワーク名> oracle
$ docker network connect <ネットワーク名> <開発用コンテナ名>
```
- ORACLE コンテナは再作成しない前提
    - 再作成する場合は docker run に --network <ネットワーク名> オプションを指定してコンテナを作成する
        - これで docker network connect <ネットワーク名> oracle を実行した状態にできる
- 開発用コンテナも rebuild コマンドを実行しない限り再作成されない
    - devcontainer.json へネットワーク設定を後から書き込んだ場合、それが適用されるのは rebuild の後になる
