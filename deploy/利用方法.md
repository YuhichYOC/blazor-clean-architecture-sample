# 前提
- baseline, rcl, without_dip の複数を同時起動してはならない
    - コンテナ名や利用ポートが衝突する

# メモ
- docker network の準備は docker compose が自動で解決してくれる
- asp.net コンテナから oracle への接続は appsettings.json の内容で行う

# baseline を起動したあと
- rcl を起動したいなら docker compose down を必ず行う

# baseline 初回起動
```bash
$ cd deploy/baseline/
$ docker compose up -d --build
```

## サンプルアプリへのアクセス URL
- http://localhost:8080/bom

# 停止
- docker compose stop

# 2 回目以降の起動
- docker compose start

# サンプル停止・コンテナ削除
- docker compose down
